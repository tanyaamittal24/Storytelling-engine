# Storytelling Engine

A full-stack interactive prototype that generates dynamic story branches using an LLM backend and saves user sessions to a database. Built for the Week 4 Prototype Development assignment.

## Tech Stack
* **Frontend:** React (Vite), JavaScript, HTML/CSS
* **Backend:** Python, FastAPI / Flask, Groq API (or Mock Mode)
* **Database:** SQLite / Local DB (`backend/db.py`)
* **Version Control:** Git & GitHub
